### Per-lab design

Every VM: `linuxVm` pattern (lab 8), `Standard_B1s`, Ubuntu 24.04, S4, SSH key + `var.admin_password`, no public IP, boot
diagnostics managed, a cloud-init systemd unit for anything it serves (`python3 -m http.server` as in labs 13–17). Every lab
outputs `private_ips`, `peer_vnet_id` (the first VNet named in its row, unless peering is off) and `connect`.

- Deploys: public IP prefixes `pfx-nat` /31 and `pfx-lb` /31 (Standard, zones 1–3); NAT gateway `ng-hub` (Standard, idle 4
  min) with `pfx-nat` associated, on `snet-nat`; Standard public LB `lb-out` with frontend from `pfx-lb`
  (`public_ip_prefix_id`), backend pool, and one **outbound rule** (all protocols, 2 × 32,000 ports, idle 4, TCP reset on);
  no load-balancing rule, no inbound. `vm-nat` in `snet-nat`, `vm-lb` in `snet-lb` in `lb-out`'s pool. Both subnets
  `default_outbound_access_enabled = false`; NSGs allow nothing inbound from the internet.
- Cost: 4 prefix addresses £0.0180; NAT gateway £0.0340 + data £0.0001; LB £0.0189; B1s ×2 £0.0178; S4 ×2 £0.0036.
